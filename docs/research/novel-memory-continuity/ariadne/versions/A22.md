# A22 V37 Observation and Interpretation Boundary

- Parent: `A21`
- Hypothesis: V36 prevents the Writer from inventing physical recording
  artifacts, but A21 still allowed the Editor to convert a visible residual
  receipt fragment into a definite historical event and a device intention.
  V37 should lower this class of content retry by separating observed text,
  tentative character interpretation, and investigation action in every
  generation-facing surface.
- Prompt version: `V37`
- Variant: `ariadne-A22-v37-observation-interpretation-boundary-no-polisher`
- Extra default model calls: `0`
- Provider: OpenAI / `gpt-5.6-luna`
- Embedding: `chroma_local`
- Backup provider: disabled
- Hybrid recall: disabled
- Ariadne reference commit: `480065e77a433d490aaa4671c0f65b44bc0919f3`
- CodeGraph: synchronized before V37 code changes

## A21 failure evidence

A21 chapter 2 completed after one targeted content retry. Validator reported
that the Editor had upgraded:

- a visible residual receipt fragment into an event that had definitely
  already happened but was incompletely saved;
- the device's new prompt into a requirement that the character find that
  historical event.

This was not an artifact-ledger failure. It was an evidence-interpretation
failure: observation, explanation, and next investigation were collapsed into
one confirmed sentence.

## Controlled change

1. Add `interpretation_boundary_rules` to the deterministic chapter contract
   with `observed`, `tentative`, `investigation`, and `forbidden_upgrades`.
2. Add the same boundary to the V37 Writer execution brief without adding a
   model call or exposing the full backend contract to the Writer.
3. Add one shared V37 role-specific prompt surface for Planner, Writer,
   Editor, Validator, and Extractor. The Writer examples explicitly cover
   residual receipt fragments and prompts such as “next receipt ready for
   retrieval”.
4. Keep V36 artifact boundaries, V35 Writer execution brief, no-Polisher
   workflow, atomic publication, provider settings, and memory budgets
   unchanged.

## Expected tradeoff

V37 may make some mystery clues less declarative and require the prose to
  express uncertainty through the character's choices. That is acceptable:
  the experiment tests whether the same suspense can be retained without
  converting an interface response into a fact about history or mechanism.

## Acceptance gates

- Seven-dimensional average `>= 8.5`.
- Chapter continuity and foreshadowing payoff averages `>= 8.5`.
- Other dimensions average `>= 8.0`.
- Average content retries `<= 1`; at least 80% of generated chapters have
  zero content retries.
- Hard setting, character-state, item-state, timeline, action-ownership, and
  observation-interpretation conflicts remain zero.
- No additional model call is introduced.
- Writer snapshots contain `V37 观察与解释边界`, and the Writer brief
  contains `interpretation_boundary`.
