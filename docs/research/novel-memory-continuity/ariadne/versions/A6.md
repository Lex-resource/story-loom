- Parent: `A5` ablation; operational path remains the A3 atomic publication path

## Controlled change

A6 does not use the A5 Detail/Critic/Prudent/Polisher extra-call path. The
existing Planner, Writer, Editor, Validator, and Extractor continue to receive
the same structured handoff and chapter contract. Existing Editor-local repair
and the normal Writer retry policy remain unchanged. The explicit A6 gate event
proves that no A5 Polisher call was eligible during the run.

This is an ablation, not a production promotion. It isolates whether A5's
additional repair call helped quality enough to justify its cost. The run must
use a new project and a fresh memory namespace from the copied chapter-1 seed.

## Acceptance questions

1. Is the seven-dimension average at least as strong as A5's completed chapters?
2. Does content retry rate return toward the V12/A3 baseline?
3. Does average chapter wall-clock time fall without increasing hard conflicts?
4. Do continuity and foreshadowing remain at least `8.5` on the complete run?
