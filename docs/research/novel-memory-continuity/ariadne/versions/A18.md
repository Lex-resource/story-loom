## Controlled change

V33 keeps A17's V32 compact Planner/Writer/Editor/Validator prompt surface,
structured handoff, chapter contract, character cards, layered recall, and no
Polisher. It adds two coordinated changes:

1. Extractor guidance uses `append_progress` for observations and dynamic state
   changes on an existing memory key. `upsert` is reserved for new keys;
   `merge/upsert` replacement requires an explicit `replacement: true` marker.
2. The deterministic atom review classifies generated character-state merges
   and observation-shaped world-rule merges as normal progress. Protected
   `published/user/frozen/system` atoms, changed hard markers, and unmarked
   replacements remain hard conflicts.

No model call, memory budget, or fallback provider was added.
