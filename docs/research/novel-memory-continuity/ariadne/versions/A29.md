## Finding

A29 does not provide a valid ten-chapter quality comparison and is excluded
from version ranking. The failure is reproducible at the provider boundary:
the exact failed long Editor Prompt returns HTTP 400 in both request modes,
while a minimal request to the same OpenAI provider returns HTTP 200. This is
not evidence of a V43 content-validation result. It is a request
compatibility or upstream capacity issue that must be isolated before another
ten-chapter run.

The raw prompt snapshots, outputs, events, and manifests remain in both run
directories. No production code was changed during A29.
