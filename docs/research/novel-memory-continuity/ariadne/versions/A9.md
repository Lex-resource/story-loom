## Controlled change

A9 is an independent project and memory namespace using the copied chapter-1
seed. It keeps A8's A3 atomic memory publication, deterministic handoff,
shared chapter contract, conditional V12 evidence-surface contract, character
cards, and no extra Polisher. The only model-facing change is selecting the
already implemented V20 profile:

- restore V10/V12 prompt context budgets;
- carry only short window, countdown, and original/copy state hints;
- treat isolated evidence wording omissions as Editor-local repairs;
- keep hard facts, item state, timeline, core events, and chapter handoff
  conflicts as the only Writer-retry class.

No new handoff or summary model call is introduced. A9 uses `auto` generation
with a single batch of chapters 2-10 so a step-mode pause cannot create an
incomplete comparison sample.
