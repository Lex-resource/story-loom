## Controlled change

V43 keeps V42's authority lock and adds one compact role-specific prompt
surface to Planner, Writer, Editor, Validator, and Extractor:

1. Each chapter has one primary observable narrative delta: a choice, action,
   position, investigation goal, resource/time cost, or risk change.
2. One unresolved fact may guide a reversible investigation only when it is
   explicitly labeled as a hypothesis, pending verification, or working
   explanation. It cannot become a required confirmed event or support an
   irreversible action.
3. Editor may locally restore those qualifiers and compress repeated evidence
   operations. Missing escalation remains a warning.
4. In the A28 variant only, a validator issue that explicitly describes a
   bounded hypothesis, without an accepted-fact/timeline/location/item/core-
   event conflict, stays on the local-repair path instead of triggering a
   Writer retry.
5. Real conflicts with accepted facts remain blocking and retryable. No new
   memory layer, frontend surface, or model call is added.
