# A2 Deterministic Narrative Projections

- Parent: `A1`
- Hypothesis: deterministic story events, story segments, stage summaries, and
  foreshadowing-to-event links can improve targeted continuity without a new
  model call per chapter.
- Ariadne commit: `480065e77a433d490aaa4671c0f65b44bc0919f3`
- Prompt version: `V12`
- Provider: OpenAI / `gpt-5.6-luna`
- Backup provider: disabled
- Embedding backend: `chroma_local`

## Implementation

- Added `NarrativeIndexEntry` and migration `e2f3a4b5c6d7`.
- Added deterministic projection and persistence functions in
  `services/narrative_index.py`.
- Added event-to-chapter, segment-to-stage, stage-to-chapter, and
  foreshadowing-to-event relationships.
- Added an opt-in `narrative_index_context` field to `PipelineContext` and the
  Agent Context Bundle.
- Added role-specific prompt hints for Planner, Writer, Editor, Validator, and
  Extractor. The hint is a published projection only; it cannot replace a
  character card, accepted hard fact, or unknown boundary.
- Added the narrative index to experiment context breakdown metrics.
- No model call was added.

## Audit correction for the nine-chapter sequence

The earlier summary called the following sequence a complete ten-chapter A2
run. The raw event files and database audit show a narrower fact: chapter 1
was the manual seed, chapters 2-4 were generated in three separate
single-chapter jobs, and only chapters 5-10 belong to
`ariadne-a2-10ch-20260815`. Those four directories share one project and one
evolving memory state, but they are not one isolated ten-chapter run. The
original event files are unchanged; this correction prevents the sequence
from being used as a clean A2-vs-A0 comparison.

## Conclusion

A2 proves that the projections are persisted, idempotent, source-linked, and
usable by all five agents without adding a dedicated model call. It does not
yet pass the quality gate, and the nine-chapter exploratory sequence is not a
clean controlled comparison because its first three generated chapters came
from separate jobs. Keep the projection schema, but do not promote the
current narrative-index context to the production default. The next decision
must use a fresh A0 baseline and a fresh A2 run from the same chapter-1
snapshot before entering A3 atomic publication work.
