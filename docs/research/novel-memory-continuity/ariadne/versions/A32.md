## Hypothesis

V45 preserves hard continuity better than V44, but its first chapters still
score only `8` for character portrayal and writing quality. The generated
scene remains a sequence of interface queries and evidence explanations even
when the Planner already returns `character_goals` and `beats`. V46 projects
those existing fields into one shared dramatic turn: goal, pressure, choice,
consequence, emotional movement, and at most three beats.

## Controlled change

V46 keeps V45's compact context budgets, accepted-fact authority boundary,
unknown/candidate handling, registered-item boundary, observation boundary,
and no-Polisher configuration. It adds:

1. A deterministic `dramatic_turn` projection; no database field and no model
   call are added.
2. One compact V46 hint surface for Planner, Writer, Editor, Validator, and
   Extractor.
3. A soft quality distinction: missing character texture or repeated actions
   are warnings; hard fact, timeline, location, item, role-state, and core
   event conflicts remain blocking and retryable.

## Startup gates

- Fresh project contains only the fixed chapter-1 seed and initial character
  state; no A31 body or layered memory is copied.
- First Planner, Writer, Editor, Validator, and Extractor snapshots must
  contain `V46 戏剧转折`.
- `dramatic_turn` must appear in the Writer brief and compact review contract.
- Provider must be OpenAI-only with no backup provider.
- Only one `.venv` Worker may be running during generation.

## Result

The run was paused after chapter 7 before a ten-chapter sample could be
completed. Chapters 2-7 finished with quality events
`8.71, 8.57, 8.71, 8.71, 8.29, 8.00`; the final chapter-7 event is marked
`paused` and remains pending review because the Extractor found an accepted
world-rule conflict. Content retries were `1, 0, 1, 0, 0, 1`, with `0` JSON
recoveries and `1` API retry (the API retry was an Extractor timeout in
chapter 4). The six completed chapter events used `45` LLM attempts and
`1,774.28s` total wall-clock time. A32 is excluded from the ten-chapter
comparison, but all prompts, responses, metrics, and partial memory remain
immutable in the run directory.

The controlled change did not improve the observed character and writing
scores: they remained mostly `8`, and chapter 7's second quality event scored
writing `7` because the prose still repeated record/confirmation explanations.
The explicit dramatic-turn surface also produced soft continuity retries for
wording such as a transient field being treated as continuously visible. V47
therefore tests narrative realization without adding another story structure.
