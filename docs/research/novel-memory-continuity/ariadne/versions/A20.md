# A20 V35 Writer Narrative Execution Brief

- Parent: `A19`
- Hypothesis: A19's current-state projection reduces duplicate memory rows but
  still exposes the Writer to separate handoff, contract, outline, and memory
  surfaces. A single deterministic narrative execution brief should preserve
  continuity while reducing checklist-like prose and prompt overlap.
- Prompt version: `V35`
- Variant: `ariadne-A20-v35-writer-execution-brief-no-polisher`
- Extra default model calls: `0`
- Provider: OpenAI / `gpt-5.6-luna`
- Embedding: `chroma_local`
- Backup provider: disabled
- Hybrid recall: disabled
- Ariadne reference commit: `480065e77a433d490aaa4671c0f65b44bc0919f3`
- CodeGraph: synchronized before V35 code changes

## Controlled change

1. Add a deterministic `writer_execution_brief` projection containing the
   previous ending, current scene, inherited state, required chapter actions,
   state changes, foreshadowing actions, closing state, open questions, and
   unknown boundary.
2. For V35 Writer prompts, remove the separate handoff and contract blocks.
   The full handoff and contract remain available to other Agents, persisted
   in PostgreSQL, and retained in experiment snapshots.
3. Give Writer a narrative-only outline projection containing summary, key
   events, beats, character goals, and narrative stage. Audit-only contract
   fields remain in the canonical outline and the review pipeline.
4. Record the brief as a separate context block so its character count is
   visible in every LLM attempt.

## Expected tradeoff

The brief may hide useful detail if its deterministic budget is too small, so
the run must check continuity and foreshadowing as well as writing quality.
This is an isolated Writer-surface experiment; it does not change memory
publication, conflict routing, retrieval, or retry policy.

## Acceptance gates

- Seven-dimensional average `>= 8.5`.
- Chapter continuity and foreshadowing payoff averages `>= 8.5`.
- Other dimensions average `>= 8.0`.
- Average content retries `<= 1` and at least 80% of generated chapters have
  zero content retries.
- Hard setting, character-state, item-state, timeline, and action-ownership
  conflicts remain zero.
- No additional handoff, summary, or quality-agent model call.
- The Writer context breakdown records `writer_execution_brief_context`.
