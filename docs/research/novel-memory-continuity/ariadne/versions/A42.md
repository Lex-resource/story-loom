## Hypothesis

V55 improved action uniqueness and cross-chapter movement, but the fixed seed's
empty static character card left the result procedural. A shared, source-bounded
`character_turn` should make the same external action read as a decision made by
a particular character under a concrete pressure, without encouraging invented
backstory or adding another model call.

## Controlled change

V56 keeps V53's completed-event ledger, V54's action uniqueness, and V55's
`primary_action`. It adds `character_turn` to the chapter contract and to the
Planner/Writer/Editor/Validator/Extractor prompt projections. The field is
normalized deterministically and only accepts evidence from character cards,
accepted state, or visible chapter pressure. Technical operations remain
secondary to the character choice.
