V20 budgets, A3 atomic layered-memory publication, deterministic handoff,
shared chapter contract, character cards, V25 explicit artifact rules, and no
extra Polisher. V26 adds the corrected condition: Ariadne A7+ variants receive

disagree about whether calibration evidence is required. No new model call is
added. Generation uses auto mode and one batch for chapters 2-10.
