## Hypothesis

V46 made the dramatic turn explicit to every Agent, but the generated prose
continued to repeat interface queries and evidence explanations. Character
portrayal and writing quality remained around `7-8`, and some soft wording
differences triggered full content retries. V47 tests whether the limiting
factor is the Writer's realization of a valid structure rather than missing
memory or more Planner fields.

## Controlled change

V47 keeps V46's compact context budgets, accepted-fact authority boundary,
candidate/unknown handling, registered-item boundary, observation boundary,
no-Polisher configuration, and OpenAI-only provider. It adds no database field,
memory layer, or model call.

The only new behavior is a compact role-specific hint. Planner supplies a
concrete action anchor without inventing traits. Writer treats `dramatic_turn`
as a backstage route and renders important changes through a bounded visible
action, pause, sensory load, or relationship response. Editor locally removes
abstract repetition. Validator treats sparse characterization and style as
warnings, never a standalone rewrite trigger. Extractor stores observed
actions and state changes without inferring personality or motive.
