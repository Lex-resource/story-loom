# A15 V30 Deterministic Handoff Compression

- Parent: `A14`
- Hypothesis: A14 reduced generation-side prompt repetition, but the
  deterministic handoff itself grew from `687` to `4,986` characters by
  chapter 3 and became the dominant Writer context. A smaller execution
  projection should reduce prompt and token load without weakening continuity.
- Prompt version: `V30`
- Variant: `ariadne-A15-v30-handoff-compression-no-polisher`
- Extra default model calls: `0`
- Hybrid recall: disabled
- Backup provider: disabled

## Controlled change

A15 keeps A14/V29 Planner and Writer generation hints, the shared chapter
contract, character cards, layered-memory publication, deterministic hard
validation, and the existing retry policy. It changes only the prompt-facing
handoff projection and its per-agent budget:

- retain previous ending, end scene, present characters, inherited current
  state, next hook, current item states, current evidence propositions, and
  unknown boundaries;
- remove transition history, source references, and repeated explanatory
  provenance from the generation prompt while retaining them in PostgreSQL and
  research snapshots;
- use a 3,000-character Writer/Planner/Editor handoff budget, 3,200 for
  Validator, and 2,800 for Extractor;
- do not add a summary model call or change the V29 narrative prompt.

## Research questions

1. Does the smaller handoff keep chapter-3 continuity and foreshadowing
   quality at or above A14's `8.57/10` early signal?
2. Does Writer handoff context stay bounded as chapters accumulate?
3. Does the change reduce input tokens and wall-clock time without increasing
   content retries or hard continuity conflicts?
