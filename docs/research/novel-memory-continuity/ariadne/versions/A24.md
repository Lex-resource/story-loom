## Controlled change

V39 adds one compact role-specific prompt surface to Planner, Writer, Editor,
Validator, and Extractor:

1. Planner assigns one distinct `state_delta` to every beat and merges beats
   that only repeat a query, confirmation, or explanation.
2. Writer presents the same evidence in full once; later references must add a
   new difference, cost, choice, or consequence.
3. Editor performs local single-pass evidence compression.
4. Validator treats repeated evidence as a warning unless a core event or hard
   continuity rule is missing.
5. Extractor creates memory candidates only for new state deltas.

V38, V37, V36, V35, layered memory, character cards, atomic publication,
OpenAI-only settings, disabled hybrid recall, and the no-Polisher control remain
unchanged. No database field, memory layer, frontend surface, or model call is
added.
