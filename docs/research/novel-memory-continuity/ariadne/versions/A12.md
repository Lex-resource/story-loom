## Controlled change

A12 is a fresh project seeded from the same fixed chapter-1 snapshot used by
A9-A11. It retains A3 atomic layered-memory publication, deterministic
handoff, shared chapter contract, character cards, V20 low-retry state rules,
and V25 artifact/window boundaries.

V27 changes only the model-facing generation surface:

- Planner and Writer no longer receive the accumulated V12-V15 evidence
  checklist instructions.
- Planner and Writer receive a narrative-first rule: continuity contracts are
  backstage constraints, not prose headings or audit forms.
- Deterministic evidence-surface rules require an actual non-empty handoff
  evidence ledger; generic words such as "历史回执" no longer imply a four-
  surface evidence checklist.
- Validator and Extractor retain evidence authority for hard checks and
  memory publication.
