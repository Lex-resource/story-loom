## Controlled change

V40 adds `end_state_boundary` to the chapter contract and a compact role-aware
hint to Planner, Writer, Editor, Validator, and Extractor:

1. `end_state` describes the last observable state that has already happened,
   not a decision, intention, or next action.
2. Writer uses the boundary as the final anchor for the chapter instead of
   treating every nearby wording difference as a new event.
3. Validator distinguishes an explicitly identified soft contract ambiguity
   from a real setting, timeline, object, location, or core-event conflict.
4. Extractor records the state actually published in the chapter; the contract
   helps locate the boundary but cannot promote an unobserved state.

The existing layered memory, character cards, atomic publication, V39 rules,
OpenAI-only settings, disabled hybrid recall, and no-Polisher control remain
unchanged. No dedicated handoff or narrative-index model call is introduced.
