## Environment limitation

The current system Python has pytest but not `json_repair` or `pytest-asyncio`. The project `.venv` contains runtime dependencies but not pytest, and its binary `pydantic_core` extension is not usable from the system Python. The two failures were collection/runtime-environment failures, not A1 assertion failures. No dependency installation or environment mutation was performed in this batch.

## Decision

A1 is suitable as the compatibility foundation for A2. Do not run a ten-chapter quality comparison yet: the bundle is currently a structured adapter and the existing Agents still consume the flat fields. A2 should first add deterministic narrative projections and then migrate prompt consumers through the bundle with an explicit context-size audit, without adding a model call.
