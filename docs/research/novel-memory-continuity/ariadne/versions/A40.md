`new_stage_delta`. It adds a compact `unique_action_ledger` and a shared rule:
one operation, one observed response, one resulting change. It also routes
only same-operation resubmission and unknown-label over-assertion through the
existing Editor repair path. Hard accepted-fact, timeline, location, and
core-event conflicts remain Writer-retry or blocking issues.
