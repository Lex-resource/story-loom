- Hypothesis: V37 protects the observation/interpretation boundary, but the

## A22 evidence

A22-r2 chapter 2 scored `8.71/10` with zero content retries. Chapter 3
scored `8.43/10` with zero content retries, but the quality record still
described repeated observation/confirmation and mechanical interface prose.
The Writer memory context grew from `2,031` characters in chapter 2 to
`6,519` in chapter 3, and the Validator reached `8,507` characters. The run
was paused before chapter 4, so it cannot establish a ten-chapter quality
result.

## Controlled change

1. Add a V38 role-specific prompt surface to all five writing Agents.
2. Require the Planner to express beats as action/choice -> resistance or new
   information -> observable consequence.
3. Tell the Writer to remove repeated checks without a new delta, and to end
   scenes on a changed position, decision, or investigation question.
4. Tell the Editor to perform local duplicate compression, while the
   Validator treats repetition and style as warning-only unless a hard
   continuity or contract failure exists.
5. Tell the Extractor not to create duplicate memory keys for repeated
   observations.

V37's uncertainty rules, V36's artifact rules, and the existing memory and
publication code remain unchanged. No dedicated model call is introduced.
