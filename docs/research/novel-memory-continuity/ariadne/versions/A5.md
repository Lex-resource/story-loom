## Hypothesis

Making Ariadne-style quality roles conditional should reduce Writer content
retries without paying four extra calls on every chapter. The existing
pipeline supplies the roles:

- Detail: the chapter contract, handoff, and evidence context already passed to
  the validator;
- Critic: the existing comprehensive Validator call;
- Prudent: a deterministic gate that accepts only explicit hard continuity or
  fact issues;
- Polisher: one existing Editor force-revision call with the exact validator
  evidence, followed by one comprehensive recheck.

This is deliberately not four permanent nodes. Normal chapters therefore keep
the V12 call count, while a hard continuity failure may spend at most one local
repair and one recheck before falling back to the normal Writer retry path.

## Implementation

- Added `services/ariadne_quality_gate.py` with an opt-in A5 variant check,
  deterministic eligibility rules, and role events.
- Added the A5 path to `worker_support/generation_editor_flow.py`.
- Added one-per-chapter state in `worker_support/generate_job_runner.py` so a
  failed polisher cannot loop indefinitely.
- A5 does not activate for production, V12, or A4 variants.
- All role decisions and the extra call are recorded in `events.jsonl`.

## Acceptance questions

1. Does the extra local repair lower content retries per chapter?
2. Does the recheck prevent an attempted repair from hiding a real conflict?
3. Are ordinary style/evidence warnings kept out of the extra-call path?
4. Does the quality gain, if any, justify the additional calls on hard chapters?

The final metrics and conclusion will be appended after the isolated ten-
chapter run. Failed or interrupted runs remain under `data/research_runs/`.
