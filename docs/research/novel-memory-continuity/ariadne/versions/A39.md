## Hypothesis

A38 showed that an explicit visible consequence chain can still replay the
previous chapter when the next Planner/Writer does not receive a bounded list
of completed actions and the previous terminal state. V53 tests whether a
deterministic completed-event ledger plus a required non-empty `new_stage_delta`
moves the story into a genuinely new stage without adding a model call.

## Controlled change

V53 adds `completed_event_ledger` and `previous_terminal_state` to the existing
deterministic `ChapterHandoff`. The ledger is projected from the accepted prior
outline, accepted memory atoms, and terminal scene changes, then bounded before
prompt rendering. The chapter contract carries the prior progress boundary and
the Planner's `new_stage_delta`; Writer, Editor, Validator, and Extractor read
the same fields.

The shared V53 prompt inherits V52 and requires:

- Planner: a non-empty stage/entry/relationship/position/risk/strategy delta;
- Writer: a short bridge from the previous terminal state followed by a new
  stage, rather than a complete replay;
- Editor/Validator: explicit replay evidence and no-stage-delta reporting;
- Extractor: only new progress enters memory; inherited/replayed material is
  not a new memory update.

No new database field, memory layer, frontend surface, or model call is added.

## Acceptance

The V53 sample is eligible for ten-chapter comparison only if it has no hard
continuity conflict, average content retries at most one, at least 80% retry-free
chapters, and no repeated previous terminal state without a justified new
stage delta. The project-wide quality gates remain seven-dimensional average
`>= 8.5`, continuity and foreshadowing `>= 8.5`, and zero hard setting,
character-state, and timeline conflicts.

The chapter-4 failures were not a replay of the previous chapter's terminal

submitted the same local verification twice, and a later draft rendered the
unknown field type as the asserted property `不可见` instead of `待判定` or
`未返回`. V53 therefore succeeds on its cross-chapter hypothesis but fails
the low-retry runtime gate. The raw events, prompts, and responses remain
unchanged. A40/V54 targets these two local classes without changing the V53
handoff ledger.
