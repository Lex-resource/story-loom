## Controlled change

V41 adds one compact role-specific prompt surface to Planner, Writer, Editor,
Validator, and Extractor:

1. Planner compares the previous investigation objective with the current
   start state and plans one observable strategy change, character choice,
   resource/time cost, or risk change.
2. Writer performs one complete evidence pass, then dramatizes a permitted
   action or consequence. Repeating the same query, save, or door test does not
   count as progression unless it produces a new result or real cost.
3. Editor compresses repeated investigation operations and foregrounds choices
   and consequences without creating new entities, permissions, sources, or
   causal facts.
4. Validator reports missing escalation as a quality warning only. It does not
   trigger a Writer retry unless a hard continuity, core-event, or structure
   failure is also present.
5. Extractor persists only observed choices, strategy changes, costs, risks,
   and position changes as new state deltas; repeated evidence does not create
   duplicate memory keys.

V40 terminal-state boundaries, V39 single-evidence rules, layered memory,
character cards, atomic publication, OpenAI-only settings, disabled hybrid
recall, and the no-Polisher control remain unchanged. No database field,
frontend surface, memory layer, or dedicated model call is added.

## Result

limit. Chapters 2-4 completed with scores `8.80`, `8.40`, and `8.20`; chapter
5 reached `8.60` after repair but was not published because a later cross-
chapter direction conflict remained. The completed chapters had content retry
counts `0, 0, 1`; chapter 5 recorded `3` retries and ended `paused`.

The failures were hard issues, not style warnings: chapter 4 disconnected a
voice/input path and later continued to hear the door response; chapter 5
first upgraded an ambiguous sender label into an identity/causal claim, then
reversed the direction of a footprint already established in chapter 4. V41
therefore remains a partial excluded sample. Raw events and prompt snapshots
