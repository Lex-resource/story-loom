## Controlled change

V42 adds one compact role-specific prompt surface to Planner, Writer, Editor,
Validator, and Extractor:

1. Narrative escalation may only be an observable action, position, permitted
   investigation goal, resource/time cost, or risk change.
2. Identity, sender, source, executor, ownership, causality, historical
   direction, channel state, and item direction remain unknown unless accepted,
   published, or frozen evidence confirms them.
3. Writer and Editor must preserve previously published direction, channel,
   item, and action states unless the text shows an observed intermediate
   transition.
4. Validator keeps those authority and cross-chapter violations as hard
   conflicts. Missing escalation, repetition, and weak character reaction stay
   warnings and cannot trigger Writer retries by themselves.
5. Extractor records only observed deltas and leaves ambiguous labels as
   `candidate/unknown` observations rather than accepted memory keys.

V41, V40, V39, layered memory, character cards, atomic publication,
OpenAI-only settings, disabled hybrid recall, and the no-Polisher control remain
unchanged. No database field, frontend surface, memory layer, or dedicated
model call is added.
