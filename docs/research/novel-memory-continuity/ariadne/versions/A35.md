## Problem From A34

A34 fixed the generated world-rule observation merge boundary, but chapter 2
still paused after three content retries. Validator correctly identified two
variants of the same error: an interface label was treated as proof of a real
historical record, and then the draft presupposed an actual sender, request,
and causal explanation. These are local wording errors when no accepted fact,
timeline, location, item, or core event changes.

## Controlled Change

V49 adds a compact evidence-language hint to all five writing Agents. It gives
explicit safe wording (`显示/标注/可见片段/是否对应/仍无法确认`) and forbids
unsafe upgrades (`承认真实存在/曾提交/导致` for unknown history and causality).

When every Validator hard issue in a failed result matches this narrow class,
the Editor receives the exact error and performs one targeted local repair. The
result is validated again. A successful repair records `local_editor_repair`
and does not increment `content_retry_count`; a failed repair falls back to the
existing Writer retry and blocking rules. Real hard conflicts never qualify.
