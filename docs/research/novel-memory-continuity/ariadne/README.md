## 当前结论

值得研究的部分：

1. 按 Agent 组装结构化上下文区块，并保留来源和元数据。
2. 在四层记忆旁建立故事事件、故事段和阶段脉络的内部投影。
3. 对候选事实保留来源、版本和冲突队列，不让高风险候选直接覆盖权威事实。
4. 用数据库事务原子提交章节记忆沉淀，向量库继续作为提交后的可重建投影。
5. 评估全文检索与 Chroma 向量召回的确定性混合排序。

暂不作为生产默认：

- Rust/.NET 桌面工作流整体迁移。
- Detail、Critic、Prudent、Polisher 全部常驻。
- 额外的逐章模型摘要调用。
- 直接复制 Ariadne 源码或提示词。

生产默认现为 A28/V43。Ariadne 研究版本使用 `A0`-`A52` 编号，与原有 V0-V42 提示词实验隔离，失败结果和原始事件全部保留。A29 是 V43 的独立复测，但两次均因 OpenAI 上游对长结构化请求返回 HTTP 400 而未形成十章样本；A30 及后续版本继续作为研究记录，不覆盖 A28/V43 的生产选择。
