# V23 时间锚点互斥规则

## 父版本与假设

- 父版本：V22
- 假设：V22 已消除同一倒计时周期多套数字，但第 1 章仍因精确时刻与“四十分钟后”等相对时长不一致而重试 3 次。
- 目标：没有结构化时间表时，不让模型同时自由生成无法互相核对的绝对时刻和精确相对时长。

## 具体变化

- 当正文或章节契约存在两个以上绝对时刻时，检查相邻精确“X分钟后/前”是否与时间差一致。
- 不一致且没有明确校准/新时间基准时，确定性改写为“随后”。
- 一致的相对时长保留，避免过度清洗。
- Planner、Writer、Editor、Validator、Extractor 共用时间锚点规则。
- 不增加模型调用，不修改 V20、V21、V22 的原始实验。
