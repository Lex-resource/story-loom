# V20 低重试跨章状态方案

## 假设

V19 的质量和连续性较好，但内容重试明显升高，主要因为证据表面缺项、术语混用和重复登记被 Validator 作为 Writer 重写触发条件。V20 保留 V12 的证据表面规则和低重试策略，只吸收 V19 的跨章窗口/倒计时状态卫生。

## 具体变化

- 使用 V10/V12 上下文预算，不使用 V19 的超紧预算。
- 保留 V19 的已关闭窗口和倒计时单调性确定性清洗。
- 新增短版 Agent 状态提示，只传递窗口、倒计时、原件/副本三类关键状态。
- 证据字段缺失、术语混用、重复登记和说明书式表达默认交给 Editor 局部修复。
- 物品状态、时间线、地点、已接受事实、核心事件和章节承接冲突仍触发 Writer 重写。
- 不增加交接包专用模型调用；V19 原始代码和实验记录不删除。
