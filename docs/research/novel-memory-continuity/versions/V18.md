# V18 事件顺序契约卫生层

## 假设

保留 V16 的事实边界卫生和 V17 的时间算术卫生，新增同一结构化契约文本内的事件顺序检查。若同一事件同时出现“同时”和更明确的“先……才……”顺序表达，则以下游契约副本中的明确先后关系为准；不完整或无法判定的顺序不自动改写。

## 具体变化

- 识别同一事件中的“同时”“先”“随后”“才”等顺序词。
- 修正可机械判定的“同时发生”与“先发生、后触发”冲突。
- 保持 Planner 原始输出、Prompt 快照和模型响应不变。
- 不增加模型调用，不直接修改正文。

## 代码验证

V18 新增顺序冲突和顺序一致性回归测试。V18 正式实验结果写入本文件和 `results.md`。
