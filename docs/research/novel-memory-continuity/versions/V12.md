# V12 证据表面与关闭后观测

## 元数据

- 父版本：V11
- 修改假设：V11 已达到质量和重试门槛，但第 10 章仍把读取路径、帧内来源字段和设备侧执行来源压缩成同一个“来源”词；关闭登记完成后的只读监测也没有形成稳定的状态句。增加确定性证据表面规则可以减少这类局部重试，不增加模型调用或记忆召回预算。
- 研究目标：在单一 Worker 条件下复测十章，保持 V11 的质量水平，同时把来源字段混淆和关闭后状态边界问题降为 0。
- Provider：`OpenAI / gpt-5.6-luna`；备用 Provider：关闭；Embedding：`chroma_local`。

## 具体变更

1. `services/continuity_contract.py` 增加 `evidence_surface_rules` 与 `evidence_surface_claims`，确定性区分读取路径、帧内来源字段、设备侧执行回执和实体影响。
2. V12 的 Agent 提示要求使用不同限定词，不允许“来源显示为”同时承担读取路径和帧内来源字段含义。
3. 关闭执行登记完成后的响应必须明确位于保留的只读监测列表中，状态仍为关闭且控制链未重新开放。
4. 阶段性证据链必须说明基于共同校准脉冲形成，仅表示报告级归并或结构/周期对应，不表示同源、因果、归属、发送者或操作者确认。
5. Planner、Writer、Editor、Validator、Extractor 共用同一组规则；不增加交接包专用模型调用，不扩大 V11 记忆预算。

## 验证方式

先运行 Prompt/契约定向测试、完整 `pytest -q`、`compileall` 和 `codegraph sync`。正式实验使用新的项目、新的记忆和新的 `run_id`，从 V9 修复后全书骨架独立生成十章。实验期间只运行一组项目 `.venv` Worker，保留所有渲染 Prompt、原始输出和事件流。

## 预期验收

- 七维平均 `>= 8.5`；章节衔接和伏笔兑现 `>= 8.5`；其他维度 `>= 8.0`。
- 平均每章内容重试 `<= 1`，至少 `80%` 章节零内容重试。
- 来源表面混淆、关闭后状态回滚、阶段性结论越界导致的硬冲突为 `0`。
- 不新增专门用于交接包的模型调用。

## 结论

V12 达到连续性、伏笔、平均内容重试和零内容重试率门槛；未达到七维平均 `8.5` 的硬门槛，主要由人物塑造 `8.4` 和文笔 `8.0` 拉低。证据表面规则有效：最终十章没有再观察到 V11 中记录的来源字段混淆或关闭后控制链重新开放问题。

下一版本不应继续扩大记忆召回，应优先把技术调查中的字段登记压缩成动作、选择和人物反应，改善文笔与人物塑造；同时保留 V12 的证据边界规则，单独研究供应商 502 对墙钟和尝试数的影响。完整模板、渲染 Prompt、原始模型输出和事件流均保存在上述独立运行目录。
