# V5 定点重试策略

## 元数据

- 父版本：V4
- 修改假设：重试只应修复有证据的硬冲突、核心事件缺失或严重结构断裂；局部措辞和可清理问题不应再次调用 Writer。

## 具体变更

1. Validator 错误上下文保留类别、错误类型、正文证据、冲突事实和修复建议。
2. Writer 重写提示词要求逐条处理证据，不允许泛化重写或补全 unknown/candidate/generated。
3. 只有事实冲突、时间线/逻辑/连续性结构问题或核心事件缺失才触发 Writer 重写。
4. 非结构性问题使用清理后的正文继续，不计入内容重试。
5. API 重试、JSON 修复和内容重写仍分开记录。

## 验证

已通过 V5 重试分类和错误证据渲染定向测试。十章实验结果待填写。
