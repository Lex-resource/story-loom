# V4 Agent 专属召回

## 元数据

- 父版本：V3.1
- 修改假设：相同的四层记忆如果按 Agent 目标裁剪，能减少无关上下文和误用候选线索，同时保留连续性所需的硬事实。
- 代码状态：本地工作区 dirty，实验记录保存代码快照和 diff 哈希。

## 具体变更

1. Planner 读取剧情阶段、plotline/character_arc 场景块、角色状态、主线推进和到期伏笔。
2. Writer 读取当前场景、出场角色状态、world_rule/character_state/foreshadowing 硬事实、交接包和章节契约。
3. Editor/Validator 读取用于审计的权威事实、角色状态、主线和伏笔，以及同一份交接包和契约。
4. Extractor 读取全量可更新类别，但仍把新提取结果作为 candidate/generated，等待审定。
5. layered 模式下空的旧 world_state、character_state、foreshadowing、plot_threads 标签不再进入最终 Prompt。
6. 每个 Agent 的记忆区增加专属使用边界，明确候选线索和 unknown 不得升级为事实。

## 验证

已通过角色过滤、场景块过滤、候选线索过滤和提示词边界定向测试。十章实验结果待填写。
