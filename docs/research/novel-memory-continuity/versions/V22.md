# V22 单一精确倒计时契约

## 父版本与假设

- 父版本：V21
- 假设：V21 的提示词已经明确要求时间算术一致，但模型仍自行创造远程倒计时和现场校准窗口，导致第 1 章 3 次内容重试。
- 目标：把倒计时数值卫生从语言提示提升为确定性章节契约，减少时间线重试。

## 具体变化

- 同一章节同一倒计时周期只保留第一个精确数值。
- 后续精确倒计时表达改写为“倒计时继续递减”，避免产生第二套时间基准。
- 只有出现“重置、校准、新周期、重新开始”等明确边界，才保留新的精确值。
- V22 接管倒计时数值处理后，V19 只继续负责跨章窗口封存，不再二次修改倒计时。
- Planner、Writer、Editor、Validator、Extractor 共用同一条 `single_precise_countdown` 契约规则。
- 不增加模型调用，不改变 V20/V21 原始实验记录。
